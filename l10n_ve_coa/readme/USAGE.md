1. Instale el módulo. También instala `l10n_ve_seniat`.
2. Vaya a **Contabilidad → Configuración → Ajustes**.
3. En **Localización fiscal**, elija **SENIAT**, **SENIAT - Básico** o
   **SENIAT - Vacío** en una compañía que todavía no tenga plan de cuentas.

Las compañías que ya tienen un plan cargado no se modifican al instalar o
actualizar este módulo. Al actualizar `l10n_ve_seniat` en una base con
compañías que usan un plan SENIAT, la migración instala este módulo sin
recargar el plan.
