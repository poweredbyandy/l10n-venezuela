Creates the **SENIAT** user and its contact, so that SENIAT auditors can
log in with read-only access to the accounting and to the SENIAT menu.

The user is created archived. Activate it only while an audit is in
progress.

The user gets these groups:

- Internal User
- Accounting / Read-only
- SENIAT - Lectura contable
- SENIAT

Use Cases / Context
===================

During a tax audit, SENIAT officers ask for access to the accounting
records. This module provides a dedicated user for them. It used to be
created by ``l10n_ve_seniat``; it is now optional.

Databases that already had the SENIAT user keep it as it was. When this
module is installed, it takes over the existing user and contact, loads
its data and then restores their active state, groups and contact data.
The password is never changed. If a user with login ``seniat`` exists
without an external id, it is reused instead of creating a new one.

Usage
=====

1. Go to *Settings > Users & Companies > Users*, filter by *Archived*
   and open the **SENIAT** user.
2. Unarchive it, set a password and share the credentials with the
   auditor.
3. Archive the user again when the audit ends.
