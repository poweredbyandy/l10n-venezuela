Adds the Venezuelan political-territorial division to contact addresses:

- The 25 Venezuelan states.
- Municipalities (``res.country.municipality``) and parishes
  (``res.country.parish``), with the official list preloaded.
- *Municipality* and *Parish* fields on contacts, filtered by the
  selected state and municipality.

Use Cases / Context
===================

Venezuelan invoices and tax documents need the fiscal address of the
customer, which includes its municipality and parish. This data used to
live inside ``l10n_ve_seniat``. It is now a separate module so that
other modules can use Venezuelan addresses without the whole SENIAT
accounting localization.

Databases that already had ``l10n_ve_seniat`` keep their states,
municipalities, parishes and the values set on contacts: when this
module is installed, it takes ownership of those records instead of
creating new ones.

Usage
=====

1. Open a contact whose country is Venezuela.
2. Select the state.
3. Select the municipality. Only the municipalities of that state are
   listed.
4. Select the parish. Only the parishes of that municipality are listed.

Changing the state clears the municipality and the parish. Changing the
municipality clears the parish.
