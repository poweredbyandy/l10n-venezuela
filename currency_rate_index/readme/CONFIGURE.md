1. Go to *Accounting > Configuration > Settings*.
2. Under *Currencies*, choose the *Moneda índice* (for example USD).
   It cannot be the same as the company currency.
3. Open *Currencies* and, for each foreign currency that needs a direct
   rate against the index, open the *Tasas índice* tab and create rates
   by date (1 unit of that currency = X units of the index currency).
