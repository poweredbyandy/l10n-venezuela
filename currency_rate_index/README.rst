Adds direct exchange rates against a configurable index currency.

When converting between two foreign currencies (neither is the company
currency), Odoo uses the index rates if both currencies have one for the
requested date. Otherwise it keeps the native conversion through the
company currency (VES).

Example with company currency VES and index currency USD:

- Native rates: 1 USD = 876 Bs, 1 USDT = 1000 Bs
- Index rates: 1 USDT = 1 USD, 1 YEN = 0.0067 USD
- Converting 100 USDT to USD returns 100 USD (index), not 114.16 USD (via VES)
- Converting YEN to USDT goes through USD: (YEN→USD) / (USDT→USD)
- If a foreign currency has an index rate and no native VES rate,
  conversions against VES go through the index (CNY → USD → VES)
- Currencies that still have a native VES rate keep that path
- Each index rate can be entered as index per unit or unit per index
  (for example USD per CNY and CNY per USD)

Use Cases / Context
===================

In Venezuela the company currency is usually VES, while commercial
operations often compare foreign currencies such as USD, USDT or JPY.

Native Odoo rates always go through VES, so USD ↔ USDT inherits the
spread between their bolivar rates. This module lets companies configure
an index currency and load direct rates against it, so those cross
conversions stay independent from the bolivar rates used for accounting.

Configuration
=============

1. Go to *Accounting > Configuration > Settings*.
2. Under *Currencies*, choose the *Moneda índice* (for example USD).
   It cannot be the same as the company currency.
3. Open *Currencies* and, for each foreign currency that needs a direct
   rate against the index, open the *Tasas índice* tab and create rates
   by date (1 unit of that currency = X units of the index currency).

Usage
=====

1. Keep native rates against VES for currencies with a direct bolivar
   rate (USD/VES, USDT/VES, …).
2. For other currencies (CNY, JPY, …), load only the index rate. Do not
   create a native VES rate: conversions use *foreign → index → VES*.
3. Each index rate has two editable values: index per unit and unit per
   index (e.g. USD per CNY and CNY per USD).
4. Leave *Moneda índice* empty to disable the feature without uninstalling
   the module.
