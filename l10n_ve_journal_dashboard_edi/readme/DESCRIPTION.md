Agrega al tablero de facturación venezolano (`l10n_ve_journal_dashboard`)
la tarjeta **Documentos sin enviar** de facturación digital.

La tarjeta cuenta las facturas, guías de despacho y retenciones de
diarios digitales con proveedor configurado que todavía no se enviaron
o cuyo envío falló. Cada contador abre la lista de esos documentos.
