Agrega al tablero de facturación venezolano
(``l10n_ve_journal_dashboard``) la tarjeta **Documentos sin enviar** de
facturación digital.

La tarjeta cuenta las facturas, guías de despacho y retenciones de
diarios digitales con proveedor configurado que todavía no se enviaron o
cuyo envío falló. Cada contador abre la lista de esos documentos.

Use Cases / Context
===================

La tarjeta vivía dentro de ``l10n_ve_edi``, que entonces dependía del
tablero. Este módulo puente une ``l10n_ve_journal_dashboard`` con
``l10n_ve_edi`` para que cada uno funcione sin el otro.

Se instala solo cuando ambos módulos están instalados.

Usage
=====

1. Configure un diario de ventas con medio de emisión digital y un
   proveedor de facturación digital.
2. Vaya a **Contabilidad > Tablero**. La barra muestra **Documentos sin
   enviar** con facturas, guías y retenciones.
3. Haga clic en un contador para abrir los documentos pendientes.

Si no hay diarios digitales con proveedor, la tarjeta no se muestra.
