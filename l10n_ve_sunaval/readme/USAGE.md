1. Abra **Contabilidad → Configuración → Plan de cuentas** para ver las cuentas
   de movimiento SUNAVAL.
2. En los informes financieros, agrupe por **Grupo contable** para ver los
   saldos por nivel del plan (por ejemplo `1318301` para la cartera de
   préstamos de vehículos).
3. Use los diarios Banco y Efectivo creados por la plantilla, o cree nuevos
   diarios bancarios. Las cuentas nuevas se generan con el prefijo
   `113010101`.
