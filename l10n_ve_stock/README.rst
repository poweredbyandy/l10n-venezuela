Venezuela SENIAT - Stock/Inventory
===================================

Módulo de localización venezolana para funcionalidades de inventario/stock.

Funcionalidades
----------------

* Añade "Sin derecho a crédito fiscal." en las notas de entrega (stock pickings) para empresas venezolanas.
