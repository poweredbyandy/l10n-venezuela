# Migración 18.0 → 19.0

Este documento es la **bitácora única** de la migración de los módulos de este
repositorio de Odoo 18.0 a Odoo 19.0. Toda persona/agente que cambie código para
la migración debe actualizarlo aquí.

- Estado global: **en curso**
- Runbot: <http://23.27.140.107/runbot>
- Trigger: `l10n-venezuela 18 -> 19` (se lanza con cada commit a `18.0`)
- Config: `Migration_19_0` = restaurar dump 18.0 + `-u all` con Odoo 19.0 +
  scripts de OCA/OpenUpgrade 19.0

## Cómo se prueba

1. Push a la rama **`19.0-migration`** (PR a `18.0` al terminar).
2. Runbot construye:
   - `<id>-18-0`: instala los 55 módulos en Odoo 18.0 y exporta el dump.
   - `<id>-19-0`: restaura ese dump y ejecuta `-u all` con Odoo 19.0.
3. Resultado y logs: en la página del build (columna 19.0) o por HTTP:
   `http://23.27.140.107/runbot/static/build/<dest-19-0>/logs/migrate_18_to_19.txt`

El build 19.0 usa el **último dump 18.0 completado** (puede ir un commit por
detrás en datos; el código siempre es el del commit actual).

## Convenciones de la bitácora

- Una sección por fecha/commit.
- Una fila por problema detectado: módulo, error (texto estable para buscar en
  el log), cambio aplicado, archivos y estado.
- Estados: `pendiente`, `en curso`, `resuelto`, `aceptado` (no aplica /
  decisión consciente).
- No marcar `resuelto` sin un build 19.0 que haya pasado ese punto.
