1. Instale el módulo **Venezuela SENIAT - Accounting** (`l10n_ve_seniat`).
2. En **Ajustes → Compañías**, configure la compañía con país **Venezuela**.
3. En **Ajustes → Contabilidad → Localización fiscal**, seleccione el plan de
   cuentas venezolano (plantilla SENIAT).
4. Si utilizará facturación digital, retenciones, IGTF o inventario fiscal,
   instale también los módulos complementarios (`l10n_ve_edi`,
   `l10n_ve_withholding`, `l10n_ve_igtf`, `l10n_ve_stock`).
