Localización contable venezolana orientada al cumplimiento de las normas del
**SENIAT** y al proceso de **homologación** del sistema de facturación ante el
organismo fiscal.

Este módulo implementa el plan de cuentas, la gestión de talonarios fiscales
(números de control), las validaciones de emisión de documentos, la
localización de contactos (RIF, municipios y parroquias), las restricciones
sobre impuestos y productos, así como reportes e integraciones auxiliares
requeridas para operar conforme a la legislación venezolana.
