Agrega al tablero de facturación venezolano
(``l10n_ve_journal_dashboard``) el indicador **Guías de despacho no
facturadas**.

Cuenta las entregas validadas con número de control cuyas líneas no
están facturadas por completo, en las compañías venezolanas que tienen
activas las guías de despacho. El indicador abre una lista dedicada de
esas guías.

Use Cases / Context
===================

El indicador vivía dentro de ``l10n_ve_stock``, que entonces dependía
del tablero. Este módulo puente une ``l10n_ve_journal_dashboard`` con
``l10n_ve_stock`` para que cada uno funcione sin el otro.

Se instala solo cuando ambos módulos están instalados.

Usage
=====

1. Active las guías de despacho en la compañía venezolana.
2. Valide una entrega que genere número de control.
3. Vaya a **Contabilidad > Tablero**. La barra muestra **Guías de
   despacho no facturadas**.
4. Haga clic en el indicador para abrir las guías pendientes de factura.
